## Описание

Браузерная игра 2048 на чистом JavaScript, HTML и CSS. Сетка и плитки создаются динамически через DOM API. Сторонние JavaScript- и CSS-фреймворки не используются.

## Возможности

- Поле 4×4, старт с 1–3 случайными плитками.
- Управление стрелками клавиатуры, свайпами и экранными кнопками.
- Объединение плиток во всех четырёх направлениях и начисление очков.
- Появление новых плиток со значением 2 или 4 после успешного хода.
- Проверка окончания игры, когда больше нет возможных ходов.
- Отмена последнего хода.
- Сохранение и восстановление игровой сессии, включая возможность отмены последнего хода.
- Сохранение рекорда по имени и дате, таблица лучших 10 результатов.
- Адаптивная вёрстка и визуальные эффекты появления плиток.

## Запуск локально

Откройте `index.html` в браузере или запустите сервер из корня репозитория:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000/lab3/.

## Публикация через GitHub Pages

В настройках репозитория откройте Settings → Pages, выберите Deploy from a branch, ветку `main` и каталог `/ (root)`. После публикации игра будет доступна по адресу выше.

## Что показать в видеодемонстрации

1. Начать игру и сделать несколько ходов стрелками.
2. Показать объединение плиток и изменение счёта.
3. Отменить последний ход и продолжить игру.
4. Обновить страницу и показать восстановление партии.
5. Завершить игру, сохранить имя и результат.
6. Открыть таблицу лидеров и показать сохранённый результат.
7. На телефоне или в режиме мобильного просмотра показать экранные кнопки/свайпы.

## Хранение

Игровая сессия и таблица рекордов хранятся в `localStorage` браузера. Данные локальные для конкретного браузера и устройства.
