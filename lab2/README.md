# Лабораторная работа №2 — ToDo-лист

Приложение для управления задачами на чистом JavaScript. Интерфейс создаётся через DOM API, без фреймворков.

## Возможности

- Добавление, изменение названия и срока, удаление задач.
- Отметка выполнения с зачёркиванием текста.
- Поиск по названию и точной дате, фильтр по статусу.
- Сортировка по сроку в обе стороны.
- Перетаскивание за значок в ручном режиме; кнопки со стрелками для мобильных устройств.
- Сохранение задач и их порядка в localStorage.

## Запуск

Откройте index.html или запустите локальный сервер из корня репозитория: `python -m http.server 8000`, затем откройте http://localhost:8000/lab2/.

## Публикация

GitHub Pages: в Settings → Pages выберите Deploy from a branch, main, / (root), затем Save. Адрес после публикации: https://vappross2.github.io/WEB/lab2/

## Проверка

Добавьте несколько задач с разными датами, измените одну из них, отметьте выполненную, проверьте поиск и фильтры. В ручном режиме перетащите задачу и обновите страницу: порядок и содержимое должны сохраниться.
